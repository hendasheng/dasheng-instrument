# Loudroom 0.1

Status: current baseline.

0.1 的目标是建立第一条可玩的练习闭环，而不是一次性做完整课程、完整乐理库或完整吉他工具箱。

## Core Loop

```text
Choose Key
↓
Choose Scale
↓
See Scale Notes
↓
See Fretboard Mapping
↓
Click and Listen
```

## Scope

- Web app shell
- Key selector
- Scale selector
- Interactive scale note summary
- Standard guitar fretboard, 0-15 frets
- CAGED position highlighting with selectable C, A, G, E and D shapes while retaining the full scale as context
- Full-width scale strip above one row of left-aligned Position and right-aligned Labels controls
- Position control separates the unfiltered `All` state from the `C / A / G / E / D` CAGED shape group
- Mobile hides the Position and Labels headings and keeps both control groups on one compact, non-wrapping row
- Mobile reduces workbench padding by roughly one third to preserve content width
- Portrait-mobile vertical fretboard with six string columns and frets arranged top to bottom
- Compact mobile layout hides the duplicate current-context summary and keeps the workbench header and scale strip on one line
- Mobile play control keeps the play button aligned to the full width of its label
- Standard tuning: `E A D G B E`
- Scale note highlighting
- Root note highlighting on fretboard
- Fretboard label modes:
  - Note
  - Degree
  - Root
- Click-to-play scale notes
- Click-to-play fretboard notes
- Play/stop current scale
- Hardware-style green signal light on the play button pulses with each played note
- Loop current scale playback
- Pause for two note intervals between loop repetitions
- Reuse one Web Audio context and clean up per-note nodes for sustained mobile loop playback
- Show synchronized click feedback on the current scale-strip note during playback
- GitHub Pages live demo

## UI Decisions

- Dark solid UI, not translucent neon.
- Key can stay expanded because there are only 12 notes.
- Scale should stay collapsed because the list will grow.
- Fretboard label mode belongs near the fretboard, not in the global controls.
- Fret numbers are not shown; use fret marker dots instead.
- Scale summary should be visually lighter than the fretboard.
- Fretboard is the main visual object.

## Audio

Current audio uses a Web Audio API oscillator. This is only a first preview layer.

Oscillator playback uses a normal listening gain with short attack and release ramps to avoid clicks.

Future audio work can introduce Tone.js sampler support and guitar samples organized by string and fret.
